# 🍽️ Dona Tatá Gastrobar

Site institucional desenvolvido em Angular 18 para um restaurante/gastrobar, com foco em layout moderno, responsivo e boa experiência do usuário.

## 🚀 Tecnologias utilizadas

- Angular 18
- TypeScript
- HTML5
- CSS3
- Git e GitHub

## 📱 Funcionalidades

- Página inicial com imagem de fundo (Hero)
- Botão de chamada para ação (CTA)
- Layout responsivo (Desktop e Mobile)
- Estrutura de componentes organizada

## 🎯 Objetivo do projeto

Projeto desenvolvido para fins de estudo e portfólio, com o objetivo de praticar:

- Componentização no Angular
- Estilização profissional com CSS
- Responsividade
- Versionamento com Git

## 🛠️ Como executar o projeto

```bash
npm install
ng serve
```
